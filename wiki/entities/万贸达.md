## Description

[[万贸达]]是万联生态旗下的AI驱动一站式[[大宗商品交易平台]]，覆盖有色、黑色、农粮、石化四大核心品类。依托[[多智能体协同]]实现资讯、交易撮合、招投标信息推送等全链路数智化服务，通过[[仓贸融一体化]]和[[云仓]]、[[订单e贷]]等支柱业务打通仓储、贸易与[[供应链金融]]，实现物流、商品流、资金流三流合一。

## Key Features

- **全品类覆盖**：有色（矿山至终端全链路）、黑色（点对点跨区贸易、集采代销）、农粮（谷物、油籽油料、生鲜冻品）、石化（普惠供应链金融、技术支持）
- **两大支柱业务**：[[云仓]]（仓-货-贸-融一体化）、[[金融]]（订单e贷，低利率高额度放款快）
- **客户价值**：降本（智能体比价）、提效（缩短采销周期）、数据上链透明
